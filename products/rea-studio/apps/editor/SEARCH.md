# Literal saved-file workspace search

The preceding literal-source proof below remains historical. This new work-only candidate additionally provides bounded whole-word and regex search; see [SEARCH-PATTERNS.md](SEARCH-PATTERNS.md) for exact worker, syntax, cancellation and original-engine differences. No production installation or whole-workbench acceptance follows from this candidate.

This isolated candidate adds a usable search panel and authenticated search API to Lab Editor. It searches saved valid UTF-8 regular files and opens results at one-based line/UTF-16 column positions. Case-sensitive and Unicode case-insensitive literal queries are supported. Opening a result preserves an existing unsaved draft; revision mismatches refuse stale result positions. Delayed search/read responses do not replace a later search, selected file, new draft or disposed search view in the finite modeled cases.

The search walks at most1,000 files,10,000 directory entries and12 levels below the workspace root, excluding links/junctions, `.git`, `node_modules` and `.rea-save-` temporary names. It accepts2 MiB per file, reads32 MiB in aggregate, returns at most1,000 matches with400 UTF-16-unit previews, accepts32 KiB single-line queries and refuses responses exceeding2 MiB. File/entry/read bound detection may inspect one extra entry/byte. The5-second deadline is cooperative between filesystem/line/match operations; it is not a hard cancellation deadline for a blocked OS read or regex-engine execution. Files may change between reads; revisions identify each observed file's exact bytes, not an atomic whole-workspace snapshot. External processes racing link checks remain outside the host's confinement proof.

The original comparator invokes the `@vscode/ripgrep-universal` binary from the officially downloaded VS Code1.140.0 Windows x64 distribution (commit07f806f999227108933c2e30515b26eecc1fda74). The signed distribution and every extracted file are authenticated separately by the original-acquisition record. Twenty query groups compare465 exact path/line/column/end-column positions on ordinary valid UTF-8 files, including Unicode, literal metacharacters, non-overlap, CRLF, BOM, spaces in names and explicit common exclusions. The captured run uses21 bounded original engine invocations: one version query plus20 searches. An earlier manual version invocation has only a parent conversation tool result, not a separately captured raw file. Neither engine invocation is an original VS Code workbench/GUI session.

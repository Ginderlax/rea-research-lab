# Node-RED study attribution and publication scope

This project studies @node-red/nodes 5.0.8, acquired as an exact official npm tarball. The original tarball, extracted release code, and full raw REA runs remain local under artifacts and are excluded from Git. The published material comprises research reports, manifests, selected evidence summaries, the laboratory reconstruction, demonstrations, and comparison harnesses.

The implementation was informed by inspection of emitted upstream code. It is not a clean-room implementation. This project uses Apache-2.0 conservatively for its research code and preserves upstream attribution. Copyright 2026 Ginderlax for original laboratory additions. The product name identifies the studied release and does not imply endorsement.

# Joplin study attribution and publication scope

This project studies @joplin/renderer 3.7.1, acquired as an exact official npm tarball. The original tarball, extracted release code, and full raw REA runs remain local under artifacts and are excluded from Git. The published material comprises research reports, manifests, selected evidence summaries, the laboratory reconstruction, demonstrations, and comparison harnesses.

The implementation was informed by inspection of emitted upstream code. It is not a clean-room implementation.

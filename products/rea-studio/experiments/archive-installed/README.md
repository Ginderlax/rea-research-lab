# Committed Archive acceptance

This scope tests the installed Archive source epoch. It does not compose the old
experimental overlay and does not turn an old receipt into current acceptance.
The [hosted workflow](../../../../.github/workflows/archive-installed-cloud.yml)
runs only on standard GitHub-hosted Windows with Node24.16.0.

The [read-only source helper](../../scripts/verify-archive-installed-cloud.mjs)
requires a clean committed checkout. It authenticates all62 current Archive
files against Git blobs and the fixed final census derived from the preserved
[historical source bundle](../archive-aes/bundle.json). All21 current after pins,
their exact inert source aliases,22 selected original source/manual/license
payloads and four current shared inputs are checked. The original bundle remains
labelled uninstalled: its old statement describes its own experimental epoch.
The helper performs no installation and does not verify a separate installer
receipt. A newly recorded actual installation journal is a separate artifact.

Two independent jobs establish different finite contracts:

- The fixed13 test files must produce161 passing groups with zero failures,
  cancellations, skips or unfinished checks. Original7-Zip acquisition and
  actual original-program comparison processes remain separate facts.
- Six real Chromium scenarios require three UI-created archives and five
  byte-exact restored files, correct password and refusal behavior, real
  response timing holds and disposal. This product currently has no download
  UI; the exact download and original-program execution counts are both zero.

Each job captures the62 installed files and selected original sources as inert
snapshots, records the current Git revision and run/attempt, and independently
checks source stability after every attempt that passed the initial source
check. The finite collector also authenticates every eligible active Studio Git
blob. The browser job adds a separate full eligible source/Git postcheck.
Passing tests do not excuse a failed source postcheck or incomplete artifact.
Portable evidence is capped at2500 files,96MiB raw,8MiB per file and15MiB ZIP.
Exceeding a bound fails and preserves explicitly incomplete diagnostics.

The two former overlay workflows retain their strict experimental composers and
manual triggers. They require a preserved pre-installation Git ref whose active
Archive census is47 files; they deliberately reject the installed62-file epoch.
Select such a preserved ref when replaying that historical experiment. Current
installed acceptance uses the new workflow.

The broader full-development workflow is separate. It can test the installed
application sources while explicitly composing its three bsdtar oracle-loader
test files. That is a test dependency overlay, and its exact composition and
postcheck must remain disclosed. The strict clean62-file installed helper is not
used to mislabel that modified full-test worktree as an unchanged checkout.

No result from this scope establishes every Archive feature, all ten product
replacements, a browser compatibility matrix, security acceptance, performance
superiority or full product parity. Acceptance requires actual same-attempt
cloud evidence; this document and source authoring are not a passing run.

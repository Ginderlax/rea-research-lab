# Isolated Notes search browser and observed-value study

This is a separate, source-authenticated experiment on `experiment/notes-structured-search-browser-20261019`, with the single baseline parent `2a8482b42784eb262d6d5b82e62d8d1220dc4821`. It reuses the exact eighteen reviewed feature payloads from the finite experiment. It does not install them into the active product or rewrite the finite experiment's receipts.

The browser selection is twenty retained behavior definitions (four recovery UI, eight native IndexedDB and eight New-to-do) plus eight new real Chromium search scenarios. The existing twelve recovery/storage source files stay unchanged. A separately named derivative binds the eight New-to-do bodies to all forty-six actual composed Notes source files; their entire behavior segment remains byte-exact. Its new epoch metadata explicitly treats old recovery receipts as historical context. New runtime test IDs must be observed in this attempt and matched to the frozen source-case roster.

The unchanged, pinned browser acquisition helper runs on a clean source checkout after baseline source authentication and before the eighteen feature overlays. Locked Playwright 1.64.1, Chromium revision 1248 and expected version 156.0.8078.4 are verified. The job uses one Chromium project, one worker, no retries and `forbidOnly`. New cases exercise real loopback routes, actual browser fields, native IndexedDB and unchanged actual response holds. They do not substitute synthetic DOM fixtures or fabricated server replies for browser acceptance.

The source collector preserves all selected app/test/static/config/lock/roster/collector/workflow bytes and independently enumerates all forty-one baseline and forty-six composed Notes paths. The three selected installed Playwright packages are captured in a separate bounded source group after acquisition and before product/browser execution. Their complete selected file census is re-read after execution; identical after-bytes refer to the same-attempt preserved before copy, while safe changed bytes are preserved before rejection. Node, Chromium and operating-system binary contents are external runtime assets, with observed identity/version and acquisition provenance; they are not claimed to be included in the source snapshots. Bounds cannot be widened or inputs dropped to manufacture a pass.

A second, Node-only job runs a separately pinned diagnostic derivative of the already reviewed original-search comparisons. It retains all forty-eight parser fixtures and thirty-two metadata SQL fixtures, the authenticated upstream functions and the genuine strict assertions. Actual original/replacement values or errors, generated SQL, parameters and both ID sets are written before assertions. Eighty comparison records are distinct from the eighty-two TAP parent/subtest results. The collector must physically read and authenticate the JSONL header, every ordered record and footer against the exact source pins and attempt, as well as require the real TAP results. A footer count alone does not establish complete observations.

The earlier finite epoch's successful assertions and case labels did not contain these per-case value tables. This new diagnostic job does not retroactively change that evidence or inflate the number of distinct compatibility cases. Original metadata SQL uses synthetic SQLite; the original full database, full application, FTS, normalization and ranking are not executed by this study.

Complete documented search behavior, indexing/migration reliability, original application comparisons, accessibility, performance and resource measurements remain open. Unsupported filters remain limitations. Browser results and observed tables are another step toward the original completion goal, not a new definition of completion or evidence of universal superiority.

All execution is restricted to the exact supported hosted Windows 2022/Node 24.16.0 jobs. Source and failed stdout/stderr/results are preserved with fresh same-attempt provenance and bounded evidence. The root owner must obtain a complete independent source review before pushing, then independently qualify actual artifacts and recoverable backups before accepting results or installing anything.

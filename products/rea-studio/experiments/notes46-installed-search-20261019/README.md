## Compatibility limits and required evidence

ANY uses the first modifier: exact unquoted `1` selects union; other values retain conjunction. Notebook restrictions and descendants remain independently scoped. OR negative-tag alternatives use the tagged-note complement, while conjunction can retain untagged notes. Notebook-only and empty-alternative behavior is an explicit replacement policy.

The prior original-code study has eight Lane A `notes_fts` errors and four ordinary-mirror Lane B disagreements (002, 003, 007, 008). These are unresolved original compatibility questions. This protocol does not establish Joplin GUI, persisted FTS, ranking, performance, browser-matrix or whole-product parity. The prior browser records preserve final saved-state identities and results of source-pinned equality assertions; they do not contain both standalone full before/after saved-state byte copies for independent reconstruction of every new case, nor an independent replay of every DOM transition.

For each new run, preserve the actual source/run/attempt/job identities, ordered cases, raw process streams, source captures, source-equivalence acquisition records and artifact inventories. Qualify the results independently, retain failures and verify readable recoverable local copies. Publish only reviewed, source-bound evidence. A source-only review, backup, matching after-image or historical pass does not substitute for fresh execution of this combined source.

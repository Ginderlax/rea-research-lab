# Notes ANY: isolated original-code observation campaign

This source-only campaign is a prospective experiment on the fixed parent
`ab26bf14bc1a55a723566bbafb3ca391c3ef671c`. It adds only this namespace and one
dedicated workflow on `experiment/notes-search-any-20261019`. The six candidate
product/test/document bodies are stored as inert `.snapshot` payloads. Only the
verified GitHub-hosted Windows 2022 / x64 / Node 24.16.0 job may apply the exact
declared replacements to its disposable checkout. The branch does not install
ANY into the canonical application paths, the default branch, or a local app.

The first child executes the pinned Joplin Desktop 3.6.14 parser/query-builder
code retained from original commit `7e2765a3857754d12dbadea442b60ceaf9d4b23d`.
The existing captured original sources, adapters, license and provenance remain
unchanged. The new `ANY-CASES.json` declares 16 parser comparisons, 32 synthetic
metadata SQL comparisons and eight notebook diagnostic rows. Each diagnostic
row preserves both original query-builder lanes and the replacement outcome;
it does not require notebook agreement. No Joplin desktop app, persisted Joplin
database, full-text engine or ranker is executed. The notebook plain mirror is
an explicitly synthetic diagnostic, not an FTS implementation.

The observer writes each actual value, error, SQL, parameter list and result-ID
set before its strict assertion. A complete physical stream has a header,
56 ordered case rows and a footer: 58 JSONL lines. The real TAP contract has
three parents and 56 children, hence 59 results. Only 48 rows are new strict
original/replacement comparisons; the eight notebook rows are diagnostics.
The collector reads the physical stream, binds it to the exact source, case
data, run, attempt and job, and requires the actual TAP independently. A footer
or a self-reported count cannot replace missing physical rows or failed TAP.
Failed assertions, partial observations and raw stdout/stderr are preserved.

The experiment then runs all 29 retained Notes unit, HTTP and synthetic DOM
modules. Their old 231-result basis includes the unchanged original 48 parser
and 32 SQL comparisons (82 TAP including two parents). Eleven proposed product
cases bring that declared regression roster to 242 results. These 242 and the
new 59 must be observed in cloud before acceptance; their sum is a TAP count,
not 301 distinct compatibility features. The original 80 are overlapping
regression coverage, not new observations of an original full application.

`SOURCE-PLAN.json` fixes 130 baseline source inputs: the retained 128 semantic
inputs, the real HTTP module and the bounded TAP parser. All 46 eligible Notes
files are included. Historical `results` inputs remain selected where needed,
but are excluded from the eligible Notes directory census by the exact path
component rule. The six overlay targets, including the README, are all in the
selected group. New harness/data/payload inputs are also captured. Before,
ready, post-test and restored source snapshots preserve actual bytes, SHA-256
and Git blob identity. The only allowed test-time Git changes are the six
declared replacements. Restoration refuses to overwrite unrecognized bytes or
hide undeclared changes, and verifies the original clean source again.

Each child has a fixed deadline, bounded raw output and owned-process cleanup.
No retry, skip, weakened assertion or changed oracle obtains a pass. The source
group retains limits of 256 files, 512 KiB per file and 8 MiB total. Evidence
retains 5,000 files, 8 MiB per member, 96 MiB raw and a 15 MiB inner ZIP. The
packager rejects links and unsafe/colliding names and reads every archived
member back against its pre-package hash. Bounds failure produces an explicit
incomplete fallback and a red job; it cannot qualify this experiment.

Prior 80/82, 28-browser and installed-study receipts remain bound to their own
source and attempts. This campaign cannot qualify those historical runs again.
The known unused `browserRoster` auxiliary field mismatch in the AB26 browser
source plan is recorded as an outstanding metadata erratum; this campaign
neither consumes that browser plan nor claims to repair it. The consumed
browser package roster and its actual cases had their own qualified receipts.

Real-browser ANY acceptance is a separate required next stage. Remaining
documented search work includes date, resource, source URL, ID and location
filters, full text/phrase/prefix behavior, normalization, ranking and measured
performance; notebook diagnostic differences must be resolved from actual
observations. The ten replacement products remain incomplete. No full feature
parity, performance superiority or universal replacement claim is made here.

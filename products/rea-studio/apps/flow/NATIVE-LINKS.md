# Native static Link In and Link Out

This bounded manual runner supports direct **Link In** passthrough and **Link Out** with omitted/falsy mode or `mode: "link"`. Link Out sets `msg._event` to `node:<its id>` before ordinary forwarding. It does not emit a runtime event bus. Link Call, return mode, dynamic call targets, subflow instances and external event delivery are retained as native JSON but are not executable here. Unsupported reachable nodes or options refuse preflight before any context change.

The server compiles the static graph from both Link In and Link Out `links` arrays. The union collapses duplicate destinations using JavaScript `Object.keys` order; integer-looking IDs sort before other insertion-ordered keys. An outgoing `links: []` is truthy and therefore replaces the Link Out physical wires with the compiled union, including incoming backreferences. Missing or falsy outgoing `links` preserves physical wires even if an incoming backreference exists. Native physical wires are still structurally bounded, including those overwritten during compilation. A configured virtual target must exist and be Link In; disabled nodes/tabs continue to drop deliveries. The original raw JSON and saved export text are not rewritten by compilation.

**Connect static link** adds the pair to both native lists. **Disconnect static link** removes both references; removing only the outgoing reference would leave an incoming backreference connected. When outgoing `links` is missing/falsy, disconnect leaves physical wires intact. Edit physical wires with the separate native wire controls. Dashed purple diagram edges come from the same server compiler used for execution. Link changes edit only the draft; Save and Deploy are separate actions.

The native view disables controls during an operation, guards late publications by view/draft/selection identity, and exposes an idempotent disposer to the app shell. Closing scrubs the detached native controls and prevents late response publication; it does not undo or abort an already committed server operation. Pending native operations and a detached view also refuse SVG pointer edits. These lifecycle changes cover the native workflow; the separate legacy local flow editor keeps its existing behavior.

Limits remain: 4 MiB native JSON, 1–500 nodes, IDs at most 80 characters, 100 physical output ports per node, 2,000 physical wire declarations and separately 2,000 static link declarations including duplicates. Truthy link lists must be arrays of valid IDs. Prototype-related IDs are refused and the compiler uses null-prototype dictionaries; this is an explicit bounded safety departure from upstream plain-object maps. Runs retain the existing 5,000-delivery/ten-second cooperative limits and 6 MiB queue plus Debug-result accounting. They are logical operation budgets, not process-memory isolation or stalled-I/O preemption.

This implementation is source-assisted against released Node-RED 5.0.8, under Apache-2.0. See [LINK-SOURCE-NOTICE.md](LINK-SOURCE-NOTICE.md). No original Node-RED code or dependency executes in the application. Verification alone uses the exact released graph compiler, actual Link constructors/handlers, and a test-helper runtime with original Debug sinks replaced by observers. The helper's public initializer receives an owned synthetic temporary `userDir`; a plain Node child removes inherited `NODE_TEST_CONTEXT`. Original editor/GUI executions and benchmarks are zero. The comparison preserves supplied `_msgid`, Buffer and Date values and uses exact deep comparisons without numeric tolerance or output normalization.

The focused work-stage selector comprises 57 tests: 33 existing local/native checks and 24 new checks (8 compiler/runtime bounds, 3 original-comparison groups, 10 DOM-model cases, 3 real HTTP/restart cases). The three original groups contain 9 compiler fixtures, 7 handler cases and 8 full test-helper flows; these 24 original fixtures are not 24 additional test-runner cases. HTTP cases use five private ephemeral host starts across two restarts. DOM-model checks do not constitute browser acceptance. The old 51-runtime/828-scalar comparison is a separate historical corpus and is not re-executed by this selector. Frozen staging receipts, failed attempts and source bindings are preserved below as separate epochs. Root installation and installed-path tests remain pending; the finite corrected browser review is separately bound.

No full editor/runtime compatibility, exhaustive coverage, performance comparison or product superiority is established.

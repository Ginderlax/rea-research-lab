# Independent encrypted backup review

These exact synthetic review records preserve a confirmed timestamp defect, its correction, original-program controls and 176 ciphertext/MAC comparisons against a separate cryptographic implementation. The reviewed native code is unchanged in the current checkpoint. The historical server source is preserved because a later correction changed its separate custom-snapshot branch.

The [preservation manifest](preservation-manifest.json) binds every artifact. The [original review receipt](restic-independent-review-receipt.json) retains its original local artifact names; the manifest maps them to public snapshots. Script snapshots preserve the executed bytes and include machine-local paths; they are evidence rather than a portable installation command. The current whole-suite receipt is [development validation](../development-validation.json).

This is a targeted correctness review. Cryptographic security, constant-time behavior, full product compatibility and overall superiority remain unproven.
